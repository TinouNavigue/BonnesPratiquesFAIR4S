"Quelles sont les (bonnes) pratiques d’un dépôt de code FAIR ?"
Ce dépôt contient le rapport de recherche, de L. Reversy et J. Roth sous la direction du Prof. Patrick Ruch, Sciences de l'Information, Haute école de gestion de Genève. 

DOI Conceptuel: 10.5281/zenodo.18274946. 
DOI v.1 du 16 janvier 2026 : 10.5281/zenodo.18274947 (soumission pour relecture)

Il s'agit d'une recherche exploratoire sur une cinquantaine d'articles extraits de PubMed et contenant du code logiciel. L'étude examine les pratiques de gestion de code et propose deux outils:
- un référentiel FAIR pour la gestion de code de recherche
- une checklist de bonnes pratiques FAIR
